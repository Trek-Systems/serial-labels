# Trek Serial Label Generator

Prints serial number labels on **Avery 6571** (3" x 0.625", 32 per sheet).

**Use it:** https://trek-systems.github.io/serial-labels/

1. From Notion (**tM Serial Number Generator**), click **Print labels** on the row — serials load automatically. Or load a spreadsheet with a `Serial` column ([template](serials_template.xlsx)), or paste serials.
2. Click **Print** → Scale **100%**, Margins **None**, Paper **Letter**.
3. Partly used sheet? Set **Start at label #**.

Runs entirely in the browser; serial data is never uploaded. Trek logo and QR (trek.systems/trekmount) are built in and can be swapped per computer.
First time on a new printer: tick **Print outlines**, print on plain paper, adjust **Shift right/down**.
